# «Мій семестр»

Автономний PWA-застосунок для студента: розклад пар (чисельник/знаменник), цілі з кроками, події, оцінки. Хоститься на GitHub Pages. Інтерфейс — лише українською.

Автор — студент, не програміст. Пояснюй зміни простою мовою, українською.

## Принципи (не порушувати без прямого прохання)
- **Повністю автономно.** Без бекенду, акаунтів, аналітики, викликів AI чи інших зовнішніх API. Дані — лише в `localStorage` (ключ `miy-semestr.v1`). Перенесення між пристроями — файл резервної копії (Профіль → Дані).
- **Розклад вводиться вручну.** Імпорт з фото/PDF і перевірку «за посиланням» свідомо прибрано, щоб програма не залежала від Claude. Не повертай їх.
- **Один файл `index.html`**, чистий HTML/CSS/JS без фреймворків і збірки. Зовнішнє — лише Google Fonts (Unbounded, Onest, JetBrains Mono) із системними запасними шрифтами.
- Кольори — лише через CSS-токени в `:root` (світла й темна тема через `prefers-color-scheme`).
- Основна ширина ~390px. Безпечні зони iPhone (`env(safe-area-inset-*)`) не ламати.
- Нові поля даних додавай так, щоб старі файли копії (`app:"miy-semestr", v:1`) і далі відновлювались.

## Файли
`index.html` (уся програма), `sw.js` (офлайн: network-first для файлів сайту, кеш для шрифтів), `manifest.webmanifest`, іконки `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `.nojekyll`.

## Перевірка перед здачею
1. `py -m http.server 8000` у теці → http://localhost:8000.
2. Ширина 390px, світла й темна тема: додати пару → «Сьогодні», «Тиждень», «Цілі», «Місяць», «Профіль» без помилок у консолі.
3. «Зберегти копію» → «Відновити з копії» повертає ті самі дані.

## Публікація
Закомітити в `main` → GitHub Pages оновить сайт за 1–2 хв.
