# Мій семестр

Розклад пар, цілі, події та оцінки на семестр — в одному застосунку на телефоні.

Програма повністю автономна: без сервера, без акаунта, без штучного інтелекту й без інтернету після першого відкриття. Усі дані зберігаються лише на твоєму пристрої.

## Що вміє

- **Сьогодні** — яка пара зараз чи наступна, скільки до кінця, план на день.
- **Тиждень** — пари з урахуванням чисельника й знаменника, події, кроки цілей.
- **Цілі** — кроки з датами, прогрес, автозсув графіка, черга цілей.
- **Місяць** — календар з модулями, дедлайнами й особистими подіями.
- **Профіль** — статистика, оцінки за шкалою ECTS, налаштування розкладу, резервна копія.

Розклад вносиш сам один раз на семестр: «Профіль» → «Розклад» → «＋ Додати пару». Там же вказуєш групу, дати семестру й час пар.

## Як опублікувати на GitHub Pages

1. На [github.com](https://github.com) натисни **New repository**, назви його, наприклад, `miy-semestr`, зроби **Public** і створи.
2. У новому репозиторії: **Add file → Upload files**, перетягни всі файли з цієї теки й натисни **Commit changes**.
3. **Settings → Pages**. У «Source» вибери **Deploy from a branch**, гілка **main**, тека **/ (root)** → **Save**.
4. За 1–2 хвилини програма відкриється за адресою `https://<твій-логін>.github.io/miy-semestr/`.

Файл `.nojekyll` прихований і не обов’язковий: якщо він не завантажився, нічого страшного.

## Як встановити на телефон

- **iPhone (Safari):** відкрий посилання → «Поділитися» → «На початковий екран».
- **Android (Chrome):** меню ⋮ → «Встановити застосунок» або «Додати на головний екран».

Після першого відкриття програма працює без інтернету. На iPhone краще саме встановити її на початковий екран: так Safari не видаляє її дані, навіть якщо довго не відкривати.

## Де зберігаються дані

Лише в пам’яті браузера на цьому пристрої (`localStorage`). Нічого нікуди не надсилається.

Щоб перенести дані на інший телефон чи не втратити їх: **Профіль → Дані → «Зберегти копію»**. На новому пристрої — **«Відновити з копії»** і вибери цей файл.

Якщо очистити дані сайту в налаштуваннях браузера, усе зникне, тож час від часу зберігай копію.

## Як оновити програму

Зміни `index.html` і завантаж його в репозиторій замість старого. Телефон підхопить нову версію під час наступного відкриття з інтернетом.

## Що в теці

```
index.html             уся програма: HTML, CSS і JavaScript в одному файлі
sw.js                  service worker: робота без інтернету
manifest.webmanifest   назва, іконки й вигляд після встановлення
icon-192.png           іконки
icon-512.png
apple-touch-icon.png   іконка для iPhone
.nojekyll              каже GitHub Pages віддавати файли як є
```

## Запуск на комп’ютері

```bash
py -m http.server 8000
```

Запусти в цій теці й відкрий http://localhost:8000. Можна й просто двічі клацнути `index.html`, але тоді не працюватиме офлайн-режим.
